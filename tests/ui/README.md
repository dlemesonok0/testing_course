# UI system tests

Тесты используют Playwright Test и проверяют приложение через реальный React UI:
формы, кнопки, списки, фильтры, сортировку, переходы и сообщения об ошибках.
Backend запускается как часть системы в препродовом контуре. API используется
только для быстрой подготовки данных, очистка данных намеренно не выполняется.

## Структура

```text
tests/ui/
  fixtures/
    app.fixture.ts
    data.ts
  locators/
    ProductsLocators.ts
    DishesLocators.ts
  pages/
    ProductsPage.ts
    DishesPage.ts
  products.ui.spec.ts
  products-exhaustive.ui.spec.ts
  dishes.ui.spec.ts
  dishes-exhaustive.ui.spec.ts
```

## Запуск

```bash
npm install
npm --prefix frontend install
npx playwright install chromium
npm run test:ui
```

`playwright.config.ts` автоматически запускает:

- backend на `http://127.0.0.1:8001` через `npm run dev:backend:ui`;
- frontend на `http://127.0.0.1:5173`.

UI-тесты работают с накопительной препродовой SQLite-БД:
`backend/preprod_recipe_book.db`. Перед и после тестов данные не очищаются,
чтобы контур был максимально близок к системному/preprod-использованию.
Тесты создают уникальные имена сущностей через суффиксы и не зависят от
пустого состояния базы.

## Тест-дизайн

Используются эквивалентное разбиение и анализ граничных значений:

- название продукта: 1 символ и 2 символа;
- калории: `-0.01`, `0`, `0.01`;
- сумма БЖУ продукта: `100`, `100.01`;
- фотографии: `5`, `6`;
- размер порции блюда: `0`, `0.01`;
- вес ингредиента: `0`, `0.01`;
- фильтры: совпадающая категория, несовпадающая категория, флаги.

## Покрытые сценарии

- создание продукта с валидными данными через UI;
- поиск, фильтрация и сортировка продуктов;
- создание блюда из существующего продукта;
- автоматический draft-расчет КБЖУ блюда;
- ограничение vegan-флага блюда для не-vegan ингредиента;
- запрет удаления продукта, используемого в блюде.

Расширенные граничные проверки вынесены в `*-exhaustive.ui.spec.ts`:

- валидация продукта по классам и границам;
- ограничение количества фотографий;
- границы размера порции блюда;
- границы веса ингредиента.
